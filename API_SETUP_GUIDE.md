# API Setup Guide 🔑\n\nComplete step-by-step instructions to get all API credentials configured for the automation system.\n\n## 1. OpenAI API (For Script Generation)\n\n### Get Your API Key\n\n1. Go to [OpenAI Platform](https://platform.openai.com/)\n2. Sign in with your account (create one if needed)\n3. Navigate to **API keys** (left sidebar)\n4. Click **Create new secret key**\n5. Copy the key immediately (you won't see it again)\n\n### Add to GitHub Secrets\n\n1. Go to your repo: **Settings → Secrets and variables → Actions**\n2. Click **New repository secret**\n3. Name: `OPENAI_API_KEY`\n4. Value: Paste your API key\n5. Click **Add secret**\n\n**Cost**: ~$0.01 per video (gpt-3.5-turbo is cheap)\n\n---\n\n## 2. Google Cloud / YouTube API (For YouTube & Shorts)\n\nYou already have Google Cloud — let's enable YouTube API:\n\n### Step 1: Enable YouTube Data API v3\n\n1. Go to [Google Cloud Console](https://console.cloud.google.com/)\n2. Make sure your project is selected (top left dropdown)\n3. Search for **\"YouTube Data API v3\"**\n4. Click on it → Click **Enable**\n5. Wait a few seconds for it to enable\n\n### Step 2: Create OAuth 2.0 Credentials\n\n1. In Cloud Console, go to **APIs & Services → Credentials**\n2. Click **+ Create Credentials → OAuth client ID**\n3. If prompted, click **Configure OAuth Consent Screen** first:\n   - Choose **External** user type\n   - Fill in App name: `Science Video Automation`\n   - Add your email\n   - Skip optional fields\n   - Add yourself as a test user\n   - Save and continue\n4. Back to Credentials: Click **+ Create Credentials → OAuth client ID**\n5. Application type: **Desktop application**\n6. Name: `Science Video Uploader`\n7. Click **Create**\n8. Click **Download JSON** (or the download icon)\n9. Rename the file to `credentials.json`\n\n### Step 3: Add to GitHub Secrets\n\n1. Open the downloaded `credentials.json` file in a text editor\n2. Copy the entire JSON content\n3. Go to your repo: **Settings → Secrets and variables → Actions**\n4. Click **New repository secret**\n5. Name: `GOOGLE_CREDENTIALS_JSON`\n6. Value: Paste the entire JSON (as one line is fine)\n7. Click **Add secret**\n\n### Step 4: Store credentials.json Locally (for testing)\n\n```bash\n# Clone your repo\ngit clone https://github.com/nirajmallik143-hub/daily-science-video-automation.git\ncd daily-science-video-automation\n\n# Place credentials.json in root\ncp ~/Downloads/credentials.json .\n\n# Test locally\npython scripts/main.py\n```\n\n**YouTube Quota**: 10,000 units/day (each upload ~1,500 units = ~6 uploads/day)\n\n---\n\n## 3. Meta / Instagram API (For Instagram Reels)\n\n### Step 1: Create Meta Developer Account\n\n1. Go to [Meta Developers](https://developers.facebook.com/)\n2. Click **My Apps → Create App**\n3. App type: **Business**\n4. App name: `Science Video Reels`\n5. App contact: Your email\n6. Create app\n\n### Step 2: Add Instagram Graph API\n\n1. In your app, click **+ Add Product**\n2. Find **Instagram Graph API**\n3. Click **Set Up**\n\n### Step 3: Get Access Token\n\n1. Go to **Settings → Basic** (left sidebar)\n2. Copy your **App ID** and **App Secret** (save these)\n3. Go to **Tools → Access Token Debugger**\n4. Generate a new access token:\n   - Go to **Tools → Token Generator**\n   - Select your app\n   - Select these permissions:\n     - `instagram_basic`\n     - `instagram_content_publish`\n     - `pages_read_engagement`\n     - `pages_manage_metadata`\n   - Generate token\n5. Copy the long access token\n\n### Step 4: Get Page ID\n\n1. Go back to your app dashboard\n2. Go to **Apps & Businesses → Your Business → Accounts**\n3. Find your Instagram business account\n4. Click on it to get your **Page ID**\n\n### Step 5: Add to GitHub Secrets\n\n1. Go to your repo: **Settings → Secrets and variables → Actions**\n2. Add two new secrets:\n\n   **Secret 1:**\n   - Name: `META_ACCESS_TOKEN`\n   - Value: Your access token\n   \n   **Secret 2:**\n   - Name: `INSTAGRAM_PAGE_ID`\n   - Value: Your page ID\n\n3. Click **Add secret** for each\n\n**Note**: Access tokens expire. Use **Long-lived tokens** (valid for ~60 days).\n\n---\n\n## 4. TikTok API (For TikTok Videos)\n\n### Step 1: Apply for TikTok API Access\n\n1. Go to [TikTok Developers](https://developers.tiktok.com/)\n2. Sign in (create account if needed)\n3. Click **Get Started**\n4. Create an application:\n   - Name: `Science Video Automation`\n   - Select **Creator Marketplace**\n5. Fill in details and submit application\n\n**Note**: TikTok requires approval (usually 1-3 days)\n\n### Step 2: Once Approved, Get Credentials\n\n1. Go to your TikTok Developer app\n2. Go to **Essentials** tab\n3. Copy:\n   - **Client ID**\n   - **Client Secret**\n\n### Step 3: Get Access Token\n\n1. Go to **Authorization → OAuth 2.0 Authorization Code Flow**\n2. Follow the authorization flow to get an **Access Token**\n3. The token expires in 8 hours; use **Refresh Tokens** to get new ones\n\n### Step 4: Add to GitHub Secrets\n\n1. Go to your repo: **Settings → Secrets and variables → Actions**\n2. Add three new secrets:\n\n   **Secret 1:**\n   - Name: `TIKTOK_CLIENT_ID`\n   - Value: Your client ID\n   \n   **Secret 2:**\n   - Name: `TIKTOK_CLIENT_SECRET`\n   - Value: Your client secret\n   \n   **Secret 3:**\n   - Name: `TIKTOK_ACCESS_TOKEN`\n   - Value: Your access token\n\n3. Click **Add secret** for each\n\n---\n\n## 5. Verify All Secrets Are Added\n\nGo to your repo → **Settings → Secrets and variables → Actions**\n\nYou should see:\n\n```\n✓ OPENAI_API_KEY\n✓ GOOGLE_CREDENTIALS_JSON\n✓ META_ACCESS_TOKEN\n✓ INSTAGRAM_PAGE_ID\n✓ TIKTOK_CLIENT_ID\n✓ TIKTOK_CLIENT_SECRET\n✓ TIKTOK_ACCESS_TOKEN\n```\n\n---\n\n## 6. Enable GitHub Actions\n\n1. Go to your repo → **Actions** tab\n2. Click **I understand my workflows, go ahead and enable them**\n3. The workflow `daily-post.yml` will appear\n4. It will automatically run at **9:00 AM UTC daily**\n\n### Manual Test Run\n\n1. Go to **Actions → Daily Science Video Automation**\n2. Click **Run workflow → Run workflow**\n3. Wait for it to complete\n4. Check the logs to see if everything works\n\n---\n\n## 7.
